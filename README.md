## 커밋 메시지 규칙

문제 단위로 작업을 구분할 수 있도록 앞에 문제 번호 태그를 붙입니다.

```
[b4-1] 포트폴리오 초기 구조 작성
[b4-1] 다크 모드 토글 구현
[b4-1] GitHub API 연동 완료
[b4-1] 반응형 레이아웃 수정
```

| 형태 | 사용 시점 |
|---|---|
| `[문제번호] 기능명 추가/구현` | 새 기능 작성 |
| `[문제번호] 버그명 수정` | 오류 수정 |
| `[문제번호] 파일명 리팩터링` | 코드 정리 |
| `[문제번호] README 업데이트` | 문서 작업 |
